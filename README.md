# NexuGeek 📰

> Site de notícias focado em cultura geek — animes, jogos, filmes, e-esportes e famosos — com layout moderno, responsivo e navegação por categorias.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Função |
|---|---|
| HTML5 | Estrutura e semântica das páginas |
| CSS3 | Estilização, layout e responsividade |
| Google Fonts | Fontes Inter e Quantico |
| Flexbox & Grid | Organização dos cards de notícias |

---

## ⚙️ Funcionalidades

- 📰 Seções de notícias divididas por categoria (Jogos, Filmes, E-Esportes, Famosos)
- 🗂️ Navegação por header com links para cada categoria
- 🖼️ Cards de notícias com imagem, título e tag de categoria
- 📢 Banner de propaganda com botão de call-to-action
- 📱 Layout totalmente responsivo (desktop, tablet e mobile)
- 🔗 Links externos para redes sociais (GitHub, Instagram, LinkedIn)
